Pingvin Bexio Produkte Sync synchronisiert Produkte zwischen Bexio und WooCommerce. Es ist kein zusätzliches Abo notwendig, da die Daten direkt synchronisiert werden.

== Description ==
Pingvin Bexio Produkte Sync synchronisiert Produktdaten zwischen Bexio und WooCommerce. Das Plugin ist frei verfügbar und es wird kein zusätzliches Abo benötigt. Deine Daten gehören dir: Die Produktdaten werden zwischen Bexio und WooCommerce direkt synchronisiert, ohne Umleitung über einen zusätzlichen Dienst.

== Installation ==
Copy the unzipped folder into your plugins folder. Activate the plugin via the Plugins admin page.

== Privacy Policy ==
Pingvin Bexio Sync - Produkte uses [Appsero](https://appsero.com) SDK to collect some telemetry data upon user's confirmation. This helps us to troubleshoot problems faster & make product improvements.

Appsero SDK **does not gather any data by default.** The SDK only starts gathering basic telemetry data **when a user allows it via the admin notice**. We collect the data to ensure a better user experience for all our users.

Integrating Appsero SDK **DOES NOT IMMEDIATELY** start gathering data, **without confirmation from users in any case.**

Learn more about how [Appsero collects and uses this data](https://appsero.com/privacy-policy/).
